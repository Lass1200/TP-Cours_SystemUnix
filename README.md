# Compte rendus TP UNIX – Licence Pro LPW 2025 / 2026

Ce dépôt contient les comptes rendus des travaux pratiques réalisés dans le cadre du module  
**Systèmes / Services UNIX** – Licence Professionnelle **Projet Web et Mobile (LP LPW)**.

## Contenu du dépôt

- **TP1 – Installation d’un serveur UNIX**
  - Installation minimale de Debian (Bookworm) sur machine virtuelle
  - Configuration de base du système
  - Gestion des utilisateurs
  - Configuration et utilisation de SSH
  - Vérifications système et stockage

- **TP2 – Services, processus et signaux**
  - Étude des processus UNIX (`ps`, `top`, `htop`)
  - Gestion des processus et signaux (`jobs`, `kill`)
  - Scripts shell
  - Tubes (pipes) et redirections
  - Journalisation système (`rsyslog`, `cron`, `logrotate`, `dmesg`)
  - Sécurisation de l’accès SSH par clés

## Organisation

- `TP1/` : Compte rendu du TP1 (installation et configuration Debian)
- `TP2/` : Compte rendu du TP2 (processus, signaux et journaux système)

Chaque compte rendu répond aux questions posées durant les séances de TP et inclut :
- les commandes utilisées,
- les explications et interprétations des résultats,
- les difficultés rencontrées.

## Environnement

- Distribution : **Debian GNU/Linux – Bookworm (stable)**
- Virtualisation : **VirtualBox**
- Accès distant : **OpenSSH**
